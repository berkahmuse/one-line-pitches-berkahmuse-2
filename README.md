Entry for the [make.fun bounty "A Day of One-Line Pitches"](https://make.fun/c/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3): one sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> Tell me your app idea in plain words and an AI agent will build you a real, working first version on make.fun today — no code to learn, nothing to pay to try, and if you don't love it, all you've spent is one sentence.

218 characters, one sentence.

## How it works

`main.ts` writes the pitch to `/output/entry.txt`. The text is a fixed literal, so every run produces byte-identical output.

```sh
node main.ts
cat /output/entry.txt
```
